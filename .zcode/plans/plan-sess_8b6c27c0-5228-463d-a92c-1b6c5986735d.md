# Mintamaaf Online — Homepage redesign (reference-style anime hero)

## Context
- The site is Next.js + Tailwind v4, but all visuals are hand-written custom CSS in `src/app/globals.css` (49 minified lines): CSS-gradient sky, Georgia serif headings, Arial body, text-only logo.
- `src/app/page.tsx` is a single-line JSX return: pills → hero h1 → `<GenerateForm />` → how-it-works → examples → footer.
- `src/components/generate-form.tsx` has prompt textarea + always-visible 4-field `.form-grid` (To / From / Tone / Language) + hint + submit.
- No `public/` directory exists yet.
- Goal: match the reference screenshot — anime painted meadow/sky photo background, elegant serif display font with italic emphasis, softly glowing glassy prompt box, full-name logo, and the extra fields tucked into an "Additional options" disclosure.

## 1. Hero background image (anime style)
- Download the clean candidates found via image search (best match: 1920×1080 anime painted landscape, blue sky + fluffy clouds + flowery green field, no watermark; backup: Ghibli-style hill 1920×1040). Visually inspect each, pick the closest to the reference.
- Optimize and save as `public/hero-bg.jpg` (target ≤ ~400 KB; keep a smaller/mobile variant if the file is heavy).
- Replace `.sky` CSS gradient with the full-bleed image (`background-size: cover`, center), blended at the bottom into the cream page background via gradient overlay, plus a subtle light overlay so headline text stays readable. Remove the old CSS-drawn `.hills` flower row.
- ⚠️ Caveat: web-sourced images have unclear licensing. Acceptable for a hobby MVP; flagged for replacement with an owned/AI-generated image if the project goes public.

## 2. Typography (reference style)
- `src/app/layout.tsx`: add `next/font/google` — **Instrument Serif** (regular + italic) for display headings, **Inter** for body; expose as CSS variables. (Self-hosted at build time — no runtime Google request, CSP-friendly.)
- `globals.css`: headings (`.hero h1`, section `h2`, `.eyebrow`) use the serif with italic `<em>` accents (like "From *sorry* to something special."); body switches from Arial to Inter.

## 3. Glowing prompt card
- Rework `.prompt-card`: frosted-glass white card (`rgba(255,255,255,.8)` + `backdrop-filter: blur`), soft layered outer glow (`box-shadow` white bloom + soft green-tinted drop shadow), generous radius; `:focus-within` intensifies the glow with a smooth transition — the "smooth glow" from the reference.
- Bottom row styled like the reference: hint text left ("One free creation per day · links last 7 days"), green pill send button right.

## 4. Logo — full name
- `src/components/header.tsx`: brand becomes the green ✳ mark + **"MintaMaaf Online"** (full name, as requested). Nav and CTA unchanged.

## 5. "Additional options" disclosure
- `src/components/generate-form.tsx`: move To (optional) / From (optional) / Tone / Language into a collapsible panel behind an **"Additional options ▾"** toggle button — hidden by default so the hero looks clean like the reference.
- Smooth expand/collapse (CSS `grid-template-rows: 0fr → 1fr` transition), `aria-expanded` on the button, chevron rotation.
- Collapsed state still submits defaults (`tone: heartfelt`, `language: en`) — no validation/logic changes; `src/lib/validation.ts` untouched.

## 6. Page cleanup
- Reformat `src/app/page.tsx` (currently one line) into readable JSX; keep existing copy, pills, sections and footer. Minor hero spacing tweaks so heading + card sit over the sky portion of the image like the reference.
